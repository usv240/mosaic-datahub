Mosaic is a metadata-aware privacy remediation agent built on DataHub. It catches a risk ordinary column scanners miss: harmless-looking facts can become identifying only after lineage brings them together.

Here is the core example. ZIP code arrives from support, birth date from membership, and gender from demographics. No field is direct P I I. DataHub shows where each field came from and which downstream assets inherit the combined exposure.

The landing page teaches that idea before asking a visitor to configure anything. Four presets cover research, partner audiences, a mitigated release, and a negative engineering control. A new evaluator can run the investigation without credentials, in light or dark mode.

Mosaic also screens across assets. Two tables may look ordinary alone, yet a shared entity key lets their context combine. The live estate scan exposes those pairs, the shared key, contributed families, and the strict boundary: metadata screening only, aggregate validation required, zero raw rows.

In the research case, Mosaic discovers independent column-lineage paths, then validates only aggregate group counts. The result is minimum k equals one, one hundred percent below k five, three downstream assets exposed, and zero person-level rows returned.

The agent boundary is real. A local Mistral model selected an allowlisted asset, nominated catalog columns, explained why, and drafted review text. It never writes S Q L. Mosaic compiles the only permitted aggregate query, calculates the verdict, and can veto the proposal. Both an accepted receipt and an earlier veto are public. The model proposes; policy disposes.

Mosaic does more than warn. Its mitigation lab compares privacy improvement with retained utility. Metadata-aware code generation creates a six-file pull-request bundle: a dbt model, typed contract, aggregate-only test, policy snapshot, provenance manifest, and reviewer summary. Every artifact carries DataHub context and semantic digests stable across Windows and Linux.

DataHub is the reasoning substrate, not a logo.
