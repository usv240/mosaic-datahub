# Submission video source

`08-product-walkthrough.webm` is an automated browser recording of the working product. It covers scenario switching, a full guided investigation, aggregate-only evidence, mitigations, the DataHub proposal, retained proof, and operator safety.

Use `../DEMO_SCRIPT.md` as the narration script. The hackathon still requires the narrated result to be uploaded publicly to YouTube or Vimeo and linked from the submission form. Keeping the source footage here makes that final external step reproducible and avoids confusing a repository asset with the required public video URL.

`media-manifest.json` contains hashes for this walkthrough and all nine screenshots as produced by CI.
